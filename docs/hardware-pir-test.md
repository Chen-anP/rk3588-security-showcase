# 红外输入测试

依赖 libgpiod 1.6.x（Ubuntu 22.04：libgpiod-dev、gpiod）。只读输入，不控制输出。

```bash
sudo ./build/release/src/rk3588-security -c config/rk3588-security.conf --hw-test 120 2>&1 | tee -i /tmp/pir-test.txt
```

默认输入 /dev/gpiochip1 line 7，有效电平为高；对应本机 Orange Pi 5 Ultra 物理 Pin 7。
可选配置（已有配置不必修改）：

```ini
[pir]
chip = /dev/gpiochip1
line = 7
active_level = 1
```

初始状态打印但不计为新触发。有效表示检测到移动；恢复不表示现场无人。
设备打不开、输入读失败返回 4；Ctrl+C/SIGTERM 或指定时长结束正常返回 0。
零触发不作为自动失败：静置环境可能没有移动；功能验收需配合有序动作。

测试顺序：上电稳定后无人观察 60 秒，走入/离开三轮，持续走动约 20 秒。
按输出的相对秒数计算每轮高电平持续时间，确认无人时没有持续误触发。
同一引脚已有监听程序时，先停止该程序再运行；申请失败会报告设备不可用。
本阶段只提供独立硬件测试，业务联动留至门禁状态机阶段。


## 2026-11-09 实机验证

- 板上 debug/asan/tsan/ci 各 301 项全部通过，完整代码检查通过。
- 180 秒测试正常结束：前 60 秒没有边沿；按提示进行的三轮走入/离开均记录有效与恢复。汇总 5 次有效、4 次恢复；最后一次在 170.596 秒触发，被时限截断。
- 四个完整有效周期为 13.025、16.828、13.027、13.026 秒。持续移动的实际时长未确认，不据此判断重复触发模式。
- 另一个 gpiomon 持有输入时，--hw-test 报告占用并返回 4。
- SIGINT（Ctrl+C）和 SIGTERM 均正常输出结束统计并返回 0，实测退出耗时约 0.007/0.016 秒。
- 每次信号退出后重新运行 2 秒测试均成功，确认输入资源已释放。
